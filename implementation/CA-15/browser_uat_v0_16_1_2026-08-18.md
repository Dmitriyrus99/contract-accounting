## Найденный и исправленный дефект

До исправления роль директора могла открыть Contract 360°, но API permission filtering возвращал ложные нули по Object/System/Request и другим operational sources. Причина — у source DocType не было директорского DocPerm, хотя TARGET и roadmap требуют директорскую projection/exceptions view. Blanket `ignore_permissions` не вводился.

В v0.16.1 добавлен только `read + report` без `create/write/delete` для роли `Генеральный директор` на 18 source/context DocType: Requirement, Obligation, Contract Execution Stage, Service Object, Project Object, Object System, Maintenance Schedule/Visit, Service Request, Finding, Project Document, Contractor Assignment, Project Process/Stage/Step, Stage Gate, Photo Evidence и Process Event. После migrate браузер повторно показал `Где = 2`, `Когда = 1`, `Кто = 1`, `Что сделано = 1`, `Сроки = 1`, `Аудит = 1`, `Сколько заработали = 1`. Static test проверяет read-only DocPerm каждой сущности; Frappe tests проверяют director trace и director-center exceptions source visibility.

## Browser latency smoke

Пять последовательных XHR `get_end_to_end_trace` на одном малом fixture: `94, 383, 427, 91, 110 ms`; median `110 ms`, maximum `427 ms`. Это только локальный browser smoke, не representative-volume benchmark и не load/race evidence.

## Технические ограничения стенда

На доступных pages нет product JavaScript exceptions. Console содержит повторяющийся Socket.IO polling `404/xhr poll error`: `bench serve` отдает HTTP напрямую без production reverse-proxy route `/socket.io`; отдельный Socket.IO process на `:9000` этот route на `:8000` не проксирует. Это ограничение disposable topology, а не PASS production realtime.

Первый full-app runner без `--skip-test-records` остановился до application tests на отсутствующем optional standard DocType `Payment Gateway`. Как и в предыдущих квалификациях, авторитетный full-app запуск выполняется со штатным `--skip-test-records`, поскольку versioned app tests создают собственные scoped fixtures.
